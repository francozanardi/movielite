# Roadmap

This directory holds design notes for features and initiatives that have been
discussed and scoped but not yet scheduled for implementation. Each file
captures the outcome of a specific investigation: the problem, the options
that were evaluated, and the concrete plan that was agreed upon.

The intent is to preserve context so that when a task is eventually picked up,
the reasoning behind the chosen approach — and the alternatives that were
rejected — does not have to be reconstructed from memory.

Files here are not implementation tickets. They may be reworked, deferred, or
dropped entirely as project priorities evolve.
